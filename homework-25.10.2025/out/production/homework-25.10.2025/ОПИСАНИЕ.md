# Животные: Демонстрация полиморфизма в Java

Это простая Java-программа, демонстрирующая использование объектно-ориентированного программирования, в частности полиморфизма и интерфейсов, для моделирования поведения различных животных.

## Описание программы

Программа создает массив объектов разных классов животных и для каждого животного вызывает набор методов, демонстрирующих его поведение:

- **makeSound()** - издание характерного звука
- **sleep()** - действие сна
- **fly()** - способность летать (реализуется через интерфейс CanFly)
- **run()** - способность бегать (реализуется через интерфейс CanRun)
- **swim()** - способность плавать (реализуется через интерфейс CanSwim)

## Структура проекта

Проект состоит из следующих основных компонентов:

### Базовый класс
- **Animal** - абстрактный базовый класс для всех животных

### Интерфейсы
- **CanFly** - интерфейс для животных, которые могут летать
- **CanRun** - интерфейс для животных, которые могут бегать  
- **CanSwim** - интерфейс для животных, которые могут плавать

### Классы животных
- **Dog** (Собака)
- **Cat** (Кошка)
- **Bird** (Птица)
- **Monkey** (Обезьяна)
- **Lion** (Лев)
- **Dolphin** (Дельфин)
- **Penguin** (Пингвин)
- **Snake** (Змея)
- **Turtle** (Черепаха)
- **Eagle** (Орел)

## Особенности реализации

- Каждое животное имеет имя и возраст
- Разные животные по-разному реализуют методы интерфейсов (некоторые могут летать, другие - нет и т.д.)
- Используется приведение типов для вызова методов интерфейсов
- Программа демонстрирует принцип полиморфизма - один интерфейс, множество реализаций
